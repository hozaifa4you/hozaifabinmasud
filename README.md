# Hozaifa B. Masud

Personal portfolio of a full-stack developer, designed as an open code editor.

**Live:** [hozaifabinmasud.vercel.app](https://hozaifabinmasud.vercel.app)

![Homepage](.github/homepage.png)

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · three.js · Nodemailer, deployed on Vercel.

## Run locally

```sh
bun install
cp .env.example .env   # APP_URL and the SMTP settings for the contact form
bun run dev
```

Run `bun run lint`, `bun run typecheck` and `bun run build` before pushing.
